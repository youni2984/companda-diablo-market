# 컴판다 디아블로2 레저렉션 도우미

버전: **v1.2.0 Static / Patch 3.3 기준**

Diablo II: Resurrected 참고용 정적 웹 도우미입니다. 별도 서버나 설치 없이 `index.html`만으로 실행할 수 있고 GitHub Pages 같은 정적 호스팅에도 배포할 수 있습니다.

## 가이드 데이터의 구분

블리자드 공식 패치 노트는 게임의 현재 규칙과 변경 사항을 확인하는 기준으로 사용합니다. 그러나 블리자드는 각 직업의 유일한 정답 육성 순서나 특정 사냥터 반복을 공식적으로 강제하지 않습니다.

따라서 도우미에서는 다음처럼 구분합니다.

- **공식 기준**: 현재 시즌, 패치, 직업/콘텐츠 존재 여부, 공식 변경 사항
- **추천 가이드**: 레벨별 기술 투자, 스탯 배분, 사냥터/파밍 루트, 장비 우선순위
- **예상 계산**: 사용자가 입력한 현재 피해와 장비 옵션을 기준으로 한 전후 비교값

기술별 실제 피해는 기술 레벨, 시너지, 무기 기본 피해, 힘/민첩 보정, 숙련, 오라, 치명적 공격, 적 저항, 면역, 프레임 등 여러 요소가 서로 다르게 적용될 수 있으므로 계산 화면은 장비 변경 전후 비교용으로 사용합니다.

## 인증 구조

컴판다 로또/연금복권 도우미에서 사용하던 방식과 같은 3×3 드래그 패턴 진입 화면을 적용했습니다.

- 등록 패턴은 브라우저 JavaScript에서 검증
- 인증 성공 상태는 `sessionStorage`에만 저장
- 같은 탭에서 새로고침하면 인증 유지
- 브라우저 탭/세션 종료 후에는 다시 인증 필요
- OAuth 없음
- JWT 없음
- API Key 없음
- refresh token 없음
- 서버에 저장되는 사용자 자격증명 없음

룬 보유 체크 상태만 `localStorage`에 저장하며 외부 서버로 전송하지 않습니다.

> 이 프로젝트는 서버가 없는 정적 웹앱이므로 패턴 인증은 화면 진입을 제한하는 편의 잠금입니다. 정적 JavaScript를 직접 열어볼 수 있기 때문에 서버 기반 인증과 같은 강한 보안 경계는 아닙니다.

## 요청 흐름

1. 브라우저가 `index.html`을 연다.
2. `styles.css`, `app.js`, `build-guide.js`를 로드한다.
3. `sessionStorage` 인증 상태를 확인한다.
4. 인증되지 않은 경우 3×3 드래그 패턴 화면을 표시한다.
5. 인증되면 육성 가이드, 장비·딜 변화, 룬워드, 룬 보유, MF 분석 메뉴를 사용할 수 있다.
6. 모든 검색/계산은 브라우저에서 수행한다.
7. 별도 인증 서버, 데이터베이스, API 서버와 통신하지 않는다.

## 실행

`index.html`을 직접 열거나 정적 웹 호스팅에 올리면 됩니다. Node.js, PHP, Python 서버가 필요하지 않습니다.

## 안전 범위

게임 프로세스, 메모리, 패킷, Battle.net 서버 값을 변경하지 않습니다. 드랍률 강제 변경이나 게임 데이터 변조 기능은 포함하지 않습니다.
