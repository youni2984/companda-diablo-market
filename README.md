# companda-diablo-market

## Companda D2R 매찬 분석기

Diablo II: Resurrected에서 게임 프로세스, 메모리, 패킷 또는 서버 값을 조작하지 않고 현재 Magic Find(MF)의 실효 효율을 계산하는 웹 도구입니다.

### 기능
- 현재 MF 입력
- 시간당 평균 사냥 횟수 입력
- 유니크 / 세트 / 레어 / 매직 실효 MF 계산
- 기본 대비 상대 품질 가중치 표시
- 시간당 상대 기대지수 표시
- PC / 스마트폰 반응형 화면

### 계산식
- Unique: `250 * MF / (250 + MF)`
- Set: `500 * MF / (500 + MF)`
- Rare: `600 * MF / (600 + MF)`
- Magic: `MF`

### 실행
별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

### 인증 상태
현재 저장소에는 로그인, 세션, OAuth, JWT, API Key, refresh token 또는 사용자 인증 흐름이 구현되어 있지 않습니다. 따라서 저장소 내부에서 관리되는 사용자 자격증명이나 인증 토큰도 없습니다.

### 안전 범위
이 프로젝트는 게임 데이터 변조, 메모리 패치, 패킷 조작, 서버 조작 또는 드랍률 강제 변경 기능을 포함하지 않습니다.
