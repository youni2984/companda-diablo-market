매찬 해석

MF는 유니크·세트·레어·매직 품질 판정 효율에 영향을 주지만 룬 드랍 수량 자체를 직접 높이지 않습니다. 처치 속도까지 함께 고려하세요.

구조

서버 없음. HTML/CSS/JavaScript 정적 파일만 사용합니다. 별도 로그인 서버, 세션 서버, OAuth, JWT, API Key, refresh token은 없습니다.

앱 진입 시 3×3 드래그 패턴을 브라우저 내부에서 검증하고, 인증 완료 상태는 현재 브라우저 탭 세션에만 유지됩니다.

룬 보유 체크는 localStorage에 저장됩니다. 저장값은 현재 브라우저 밖으로 전송되지 않습니다.

데이터 기준

룬워드 이름·룬 순서·홈 수·요구 레벨·부위는 D2R 공개 게임 정보와 D2Lab 룬워드 페이지를 참고해 도우미용으로 재구성했습니다.
